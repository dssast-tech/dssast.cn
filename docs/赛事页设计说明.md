## 2. 列表页 `/events/`

### 2.1 版式（对齐 fig3）

```
┌────────────────────────────────────────────────────────────┐
│  赛事                                                       │
│  院级赛事由赛事部组织报名，校内校外赛事提供信息与资源链接        │
│  [全部] [院内] [校内校外]                     [搜索…] [排序▾] │
├────────────────────────────────────────────────────────────┤
│ ┌────────────────────────────────────────────────────────┐ │
│ │  封面图（16:6，铺满，底部加暗色渐变保证文字可读）           │ │
│ │                                        ● 进行中          │ │
│ │  2026 笃实书院算法挑战赛                 ● 可报名          │ │
│ ├────────────────────────────────────────────────────────┤ │
│ │  一句话简介，两行截断……                          ( → )    │ │
│ └────────────────────────────────────────────────────────┘ │
│ ┌────────────────────────────────────────────────────────┐ │
│ │  另一场赛事（校内校外类，无报名徽章，只有「查看详情」）      │ │
│ └────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

- **单列全宽卡片**，不要做成两列网格（参考站就是单列，视觉更稳）。
- 卡片高：桌面 240–280px（图 60% + 文字 40%），移动端 200px 左右。
- 整卡可点，右下角圆形箭头按钮是装饰，真链接铺满整卡。
- 两类赛事的区分：
  - 院内（`internal`）：右上角两枚徽章，「进行中/已结束」+「可报名/报名已截止」
  - 校内校外（`external`）：只有状态徽章，**不要**出现「可报名」，避免误导

### 2.2 筛选条

- 分类 chips 一行，选中态用品牌色描边 + 浅底。
- 搜索框窄一点（240px），排序下拉三项：`报名中优先` / `时间由近到远` / `最近发布`。
- 移动端筛选条折叠成一行横滑 chips + 搜索图标。

### 3.2 Hero banner

- 高度：桌面 380–440px，移动 300px；封面图 `object-fit: cover`，上覆 `linear-gradient` 保证白字对比度 ≥ 4.5:1。
- 状态徽章在标题上方，胶囊形，半透明白底 + 深字（fig2 的「未报名」就是这个做法）。
- 两个关键日期用「标签 + 值」上下排，值用等宽数字，字号 1.25rem。
- **阶段条**是本页的灵魂：一行 N 个节点（N = 阶段数，最多 8），节点间用细线连接；当前阶段节点放大 + 实心 + 高亮，已过节点实心 + 勾，未到节点空心 + 更淡。
- 移动端（≤782px）：**阶段条改为竖向时间线**（横向塞不下 5 个阶段）。用同一份 DOM，靠 CSS 切换方向：
  - 桌面：`display: flex`，横向连线用 `::before` 绝对定位
  - 移动：`display: block`，节点左对齐，竖线用 `::after`

### 3.3 内容卡片

统一 `.event-card`：白底、1px 边框、`$radius-md`、`padding: 1.5rem`，卡片间距 1rem。标题 1.125rem/600，和 fig2 的「作品提交 / 大赛说明」一致。

「赛事说明」内部用编号小节（①②③），编号做成圆形浅底小徽章，正文 0.9375rem/1.75。

## 4. 报名表单页 `/events/{slug}/register/`（对齐 fig1）

fig1 是「左侧选手端导航 + 右侧分组表单卡片」，我们站点没有选手端导航，所以**去掉侧栏，保留分组卡片**：

```
┌──────────────────────────────────────────────────────┐
│ 在线报名                                              │
│ 请完整填写报名信息，带 * 为必填项                       │
├──────────────────────────────────────────────────────┤
│ ┌──────────────────────────────────────────────────┐ │
│ │ 🏆 一、报名信息                                    │ │
│ │  比赛 *  [ 2026 笃实书院算法挑战赛        ▾ ]      │ │
│ │  赛道 *  [ 本科生组 ] [ 研究生组 ]                 │ │
│ └──────────────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 👤 二、基本资料                                    │ │
│ │  用户类型 *  [ 学生 ] [ 校外 ]                     │ │
│ │  姓名 *           学号/证件号 *                    │ │
│ │  手机号 *         邮箱 *                          │ │
│ │  院系 *           年级                            │ │
│ └──────────────────────────────────────────────────┘ │
│ ┌──────────────────────────────────────────────────┐ │
│ │ 📎 三、作品信息（按赛事配置显示）                    │ │
│ └──────────────────────────────────────────────────┘ │
│                                                      │
│              [ 提交报名 ]   （主按钮，全宽或右侧）       │
└──────────────────────────────────────────────────────┘
```

- 分组标题前的小图标（奖杯/人像/回形针）用内联 SVG，别引图标库。
- 输入框：高 44px、圆角 8px、聚焦时品牌色 1px 描边 + 2px 浅色外环（fig1 的紫色焦点环）。
- 单选型选择题（用户类型、赛道）用**并排大按钮**而不是原生 radio 圆点（fig1 就是这样），选中态填品牌色。
- 校验错误：字段下方红字 + 边框变红，`aria-invalid` + `aria-describedby` 由我加，你只管样式。
- 两列布局在 ≤782px 变单列；「姓名/学号」这类成对字段用 `grid-template-columns: 1fr 1fr`。

## 5. 我的报名 `/me/registrations/`

简单表格或卡片列表：赛事名 + 报名时间 + 状态（已提交/有效/无效）+ 操作（查看/修改）。状态用和赛事徽章一致的颜色语义。

---

## 6. 状态与语义色

| 状态 | 文案 | 色 | 用在哪 |
|------|------|----|--------|
| `planned` | 未开始 | 灰 | 徽章 |
| `open` | 报名中 / 进行中 | 品牌蓝 `$color-brand-b` | 徽章、主 CTA |
| `closed` | 报名结束 | 橙（新增 `$color-state-closed`） | 徽章 |
| `completed` | 已结束 | 灰 | 徽章（图变灰 90%） |
| `cancelled` | 已取消 | 红（新增 `$color-state-cancelled`） | 徽章 + 顶部提示条 |
| 报名状态 | 可报名 / 已报名 / 报名已截止 | 绿 / 蓝 / 灰 | 第二枚徽章 |

- 徽章必须文字 + 颜色双编码。
- 语义色统一加到 `_variables.scss`，别在组件里写死。

## 7. 响应式与无障碍

| 断点 | 列表 | 详情 | 表单 |
|------|------|------|------|
| ≥1024 | 单列，卡片 240–280px | hero 420px，阶段条横排 | 表单宽 46rem 居中，两列 |
| 783–1023 | 单列 | hero 360px | 单列为主 |
| ≤782 | 单列 200px | hero 300px，**阶段条转竖排** | 全单列，按钮全宽 |

- 阶段条是 `<ol>`，当前节点 `aria-current="step"`；状态不只靠颜色。
- 焦点可见：`:focus-visible` 用品牌色 2px 外描边。
- 封面图必须 `aspect-ratio` 固定，防 CLS。
- `prefers-reduced-motion` 下关闭所有位移/呼吸动画。
